# 한마디

**그림 카드를 고르면, 조사·어미·높임을 붙여 자연스러운 한국어 문장으로 말해 주는 보완대체의사소통(AAC) 앱.**

`[할머니] [밥] [먹다]` → **"할머니가 진지를 드세요."** / "할머니, 진지를 드세요."
`[엄마] [쉬] [마렵다]` → **"엄마, 쉬가 마려워요."**
`[나] [할머니] [책] [주다]` → **"저는 할머니께 책을 드려요."**

## 왜 만드나

- 말하기가 어려운 사람(자폐·발달장애·뇌병변·실어증)은 그림 카드를 눌러 말한다. 국내 AAC 앱은 대개 고른 카드 이름을 차례로 읽는다("할머니 밥 먹다").
- 한국어는 조사와 어미가 뜻과 예의를 싣는다. 국내 연구도 한국어는 활용 때문에 AAC 핵심어휘가 영어권보다 많다고 보고한다(신상은·박다은, 2020).
- 해외의 문법 지원 AAC(Proloquo2Go)는 영어·스페인어·프랑스어·네덜란드어뿐이다.
- 아이는 AAC가 들려주는 말을 따라 한다. 문법에 맞는 문장을 들려주면 조사·어미까지 따라 할 기회가 생긴다. **이것은 아직 검증할 가설이다.**

## 원칙: 뜻은 사용자가, 문법은 엔진이

엔진은 조사·어미·높임만 더하고 **내용어를 지어내지 않는다**. 대형 언어 모델처럼 "풍성하게" 바꾸지 않는다.

- 출력의 낱말마다 어느 카드에서 왔는지 출처를 단다.
- 무작위 카드열 9,000개로 "모든 카드가 반영되고 카드에 없는 내용어는 생기지 않는다"를 검사한다(`tests/realize.test.ts`).
- 뜻이 애매하면 한 가지로 정하지 않고 해석 후보를 여럿 보여 준다. 사용자가 한 번 눌러 고른다.
- 규칙 기반이라 인터넷·서버·AI 호출 없이 기기 안에서 문장당 0.03ms에 돈다.

## 할 줄 아는 것

| 영역 | 예 |
|---|---|
| 조사 이형태 | 밥**을**/사과**를**, 지하철**로**/집**으로**, 내가·제가·누가 |
| 불규칙 활용 10종 | 도와요, 들어요, 지어요, 파래요, 몰라요, 푸르러요, 퍼요, 써요, 사세요, 해요 |
| 시제·말투 | 가요/갔어요/갈 거예요, 반말·해요·합쇼 |
| 서법 | 물음, 같이 하자(갈까요?), 시킴(가세요), 부탁(도와 주세요), 약속(할게요), 의지(할래요) |
| 높임 | 드시다·주무시다·계시다·드리다, 께서·께, 진지·댁, 듣는 분 높임(드실래요?) |
| 낮춤 | 존댓말에서 나→저, 우리→저희. 같이 하자는 말에선 '우리'(저희는 듣는 이를 뺀다) |
| 부정·양태 | 안/못, 공부 안 해요, 하지 마세요, 먹고 싶어요, 갈 수 있어요, 가야 해요 |
| 부르는 말 | 엄마, … / 친구야, … (반말) / 높일 분을 부르면 반말 설정이어도 존댓말 |
| 두 동사 | 놀러 가요, 밥 먹으러 가요, 씻고 자요 |

앱 기능은 다음과 같다.

- Fitzgerald Key 색 구분
- 스위치 스캐닝(묶음 → 칸)
- 사진으로 내 카드 만들기
- 문법 도움 켜기/끄기(비교 실험용)
- 익명 사용 기록과 내보내기(기기 안에만 저장)
- 오프라인 동작(PWA)

## 실측

사람이 쓴 문장(Tatoeba)에서 조사·어미를 걷어 카드열로 만들고, 엔진이 원래 문장을 복원하는지 쟀다. 조사 생략 구어를 허용하는 기준이다. 자세한 내용은 [`eval/RESULTS.md`](eval/RESULTS.md)에 있다.

| 시험용 193문장 | 1순위 | 3순위 안 |
|---|---|---|
| 복원율 | **86.0%** | **90.7%** |

튜닝은 개발용 절반에서만 했고, 시험용은 한 번만 쟀다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 엔진 단위·속성 테스트
npm run e2e        # 화면 테스트(시스템 Chrome 헤드리스)
npm run build      # dist/ — 아무 정적 서버·학교 서버에 올리면 된다
```

평가를 다시 돌리려면 `eval/.venv`에 `kiwipiepy`가 필요하다.

```bash
npx tsx eval/dump-lexicon.ts
cd eval && .venv/bin/python build_items.py data/raw/kor_sentences.tsv data/tatoeba-items.jsonl && cd ..
npx tsx eval/run.ts eval/data/tatoeba-items.jsonl eval/data/tatoeba-preds.jsonl
cd eval && .venv/bin/python score.py data/tatoeba-preds.jsonl --split dev --errors 30
```

## 구조

```
src/engine/   hangul(받침) · josa(조사) · conjugate(활용) · predicate(서술어 자질) · realize(카드→문장)
src/data/     core.ts(핵심 어휘·격틀) · pictograms.json(ARASAAC 연결)
src/app/      화면 · 스캐닝 · 음성 · 저장
eval/         사람 문장 복원 평가
```
