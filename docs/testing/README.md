## 지킬 것

1. **비교 기준은 같은 앱 안에서.** 설정의 "문법 도움"을 끄면 기존 AAC 처럼 카드 이름만 읽는다. 같은 사람이 두 방식으로 과제를 하고 비교한다.
2. **순서 효과 상쇄.** 과제 모드는 참가자 코드가 짝수면 문법 켬으로, 홀수면 끔으로 시작한다. 코드는 번갈아 준다(P01, P02 …).
3. **익명.** 기록에는 참가자 코드·카드 id·시간·누른 횟수만 남는다. 이름·사진·목소리는 없다. 과제 모드에서만 만든 문장(과제 문장)을 남긴다.
4. **3단계는 교사가 진행한다.** 장애가 있는 미성년자는 연구 윤리상 보호가 필요한 대상이다. 학생 개발자는 아동을 직접 만나 실험하지 않는다. 교사가 수업 안에서 쓰고, 보호자 동의를 받은 뒤, 익명 결과만 공유받는다. 학교의 절차가 이 문서보다 우선한다.
5. **미리 정한 지표만 보고한다.** 결과를 보고 나서 지표를 바꾸지 않는다. 나쁜 결과도 그대로 적는다.

## 결과 분석

앱의 설정 → "기록 내보내기"로 받은 JSON 파일들을 한 폴더에 모아 돌린다.

```bash
python3 eval/analyze_logs.py 폴더/
```
