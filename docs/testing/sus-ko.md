# 시스템 사용성 척도(SUS) 한국어판

각 문장에 1(전혀 그렇지 않다) ~ 5(매우 그렇다)로 답한다.

| # | 문항 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 1 | 이 앱을 자주 쓰고 싶다. | | | | | |
| 2 | 이 앱은 쓸데없이 복잡하다. | | | | | |
| 3 | 이 앱은 쓰기 쉽다. | | | | | |
| 4 | 이 앱을 쓰려면 누군가의 도움이 필요할 것 같다. | | | | | |
| 5 | 이 앱의 여러 기능이 잘 어우러져 있다. | | | | | |
| 6 | 이 앱에는 앞뒤가 맞지 않는 부분이 많다. | | | | | |
| 7 | 대부분의 사람은 이 앱을 금방 배울 것이다. | | | | | |
| 8 | 이 앱은 쓰기 번거롭다. | | | | | |
| 9 | 이 앱을 쓸 때 자신 있었다. | | | | | |
| 10 | 이 앱을 쓰기 전에 배워야 할 것이 많았다. | | | | | |

**점수 계산:**

- 홀수 문항은 (답 − 1), 짝수 문항은 (5 − 답)으로 바꾼다.
- 열 개를 더한 뒤 2.5를 곱한다(0~100).
- 68점이 평균이다.

출처: Brooke, J. (1996). SUS: A "quick and dirty" usability scale. 위 한국어 문장은 이 프로젝트에서 옮긴 것이라 검증된 공식 번역판이 아니다. 보고할 때 그렇게 밝힌다.
