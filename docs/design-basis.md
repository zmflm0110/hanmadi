# 설계 근거

"누구를 위해"(주 사용자: 말은 어렵지만 그림 카드 두세 장으로 뜻을 만드는 만 4~10세 아이)에서 출발해, 연구가 말하는 것과 앱이 어떻게 하는지를 짝지어 적는다. 연구 대부분은 비장애 아동·다운증후군 참여자 대상이라 **우리 사용자에게 맞는지는 실제 사용 평가로 확인한다**(`docs/testing`).

| 질문 | 연구가 말하는 것 | 앱이 하는 것 |
|---|---|---|
| 카드가 많으면 못 쓰나? | 카드 수를 줄이기보다 큰 판에서 일부를 가렸다가 하나씩 여는 편이 낫다. 판 크기를 바꾸면 위치가 바뀌어 손의 기억이 깨진다([AssistiveWare](https://www.assistiveware.com/learn-aac/choosing-a-grid-size)). 공간을 묶어 두고 빈칸을 나중에 채우는 방식을 제안한다([Wilkinson 외 2019 종합](https://pmc.ncbi.nlm.nih.gov/articles/PMC6436972/)). | 선생님이 **보일 카드를 고르면 가린 카드는 빈칸으로 남아** 다른 카드 자리가 안 바뀐다. |
| 무엇이 가장 어렵나? | 어린아이는 **페이지(분류) 이동**에서 가장 많이 막힌다. 2.5~3세는 분류별 페이지 판에서 낱말을 잘 못 찾았다([Drager 외 2003](https://doi.org/10.1044/1092-4388(2003/024)), [2004](https://pubs.asha.org/doi/10.1044/1092-4388(2004/084))). | **시작 판**: 핵심어 36개로 일상 문장이 **탭 이동 없이** 한 화면에서 된다(화면 테스트로 검사). 탭은 "더 많은 낱말"용이다. |
| 어떻게 배치하나? | 품사별로 모아 두면 빨리 찾고, 흩어 두면 손을 뻗기 시작하는 데 오래 걸린다(Liang 외 2016·2018, 위 종합 연구). | 시작 판을 **품사별 줄**(사람·움직임·느낌·먹을거리/곳·작은 말·대답)로 **고정 배치**했다. 6칸이라 기기가 달라도 자리가 같다. |
| 색으로 구분하면 도움이 되나? | **배경색 구분은 24칸 미만 판에서 찾기를 돕지 않고**, 어린아이에겐 방해가 될 수도 있다. 반면 그림 안의 색이 비슷한 카드끼리 모으면 빨라진다([Thistle & Wilkinson](https://pubs.asha.org/doi/10.1044/1058-0360%282011/10-0065%29), Wilkinson & Weiss 2017). | 품사 색은 **테두리**가 기본이다(교사에게 익숙한 약속은 유지). 설정에서 배경으로 바꿀 수 있다. |
| 페이지 이동 표시는? | 따로 된 메뉴 페이지보다 **옆에 붙은 그림 썸네일 막대**가 낫다(Drager 외 2004, O'Neill 외 2018). | 탭마다 **대표 그림**을 붙이고 판 바로 위에 막대로 둔다. |
| 막 시작하는 아이는? | 격자보다 **장면 그림판**(VSD)에서 말을 더 많이 한다(Light 외 2016, Drager 외 2018). | 아직 없다(다음 후보). |
| 한국어라서 다른 점은? | 한국어는 활용(시제·존칭·문장 유형) 때문에 AAC 핵심어휘가 영어권보다 많고, 핵심어휘 목록은 어간형이다(신상은·박다은 2020). | 카드는 어간 하나(`먹다`), 활용은 엔진이 맡는다(먹어요·드세요·먹고 싶어요 …). |
| 글을 모르는 아이는? | 주 사용자는 아직 글을 못 읽는다. | 해석 고르기를 **큰 말하기 버튼 + 다르게(작은 소리로 미리 듣기)**로 한다. 그림 단서(📣 부르기, 💬 누구 이야기)를 단다. 모든 버튼에 그림·기호가 있는지 화면 테스트로 검사한다. |
| 손이 자리를 기억하나? | 운동 계획(motor planning): 자리가 늘 같아야 손이 기억한다(LAMP, AssistiveWare). | 카드는 스스로 자리를 옮기지 않는다. 앱이 배우는 것은 **해석 순위뿐**이다(화면 테스트로 검사). |
